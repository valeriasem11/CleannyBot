# Cleanny

Телеграм-бот, который убирает из групповых чатов сообщения других ботов:
пришло сообщение от бота — через заданное время оно удаляется.

## Структура

```
bot.py            точка входа (диспетчер, воркер удаления, сторож)
config.py         настройки из переменных окружения
storage.py        база данных: настройки чатов, очередь удалений, статистика
handlers.py       слежение за группами, /keep, чистка команд к ботам
commands.py       команды: /setdelay, /pause, /whitelist, /night, /stats ...
settings_ui.py    меню /settings на кнопках
queue_worker.py   воркер: удаляет созревшие сообщения пачками по 100
alerts.py         оповещения владельцу об ошибках и зависании
chat_tracker.py   запоминает чаты, следит за правами бота
utils.py          проверка админов, разбор времени, поиск бота
Dockerfile, Procfile, docker-compose.yml, cleanny.service   варианты запуска
```

## Как это работает

1. Сообщение от бота попадает в таблицу `pending_deletions` со временем удаления.
2. Воркер раз в 3 секунды берёт созревшие записи и удаляет их пачками по 100
   (`deleteMessages`) — это снижает риск упереться в лимиты Telegram.
3. Очередь лежит в базе данных, поэтому переживает перезапуски и передеплой
   (при подключённом PostgreSQL).
4. Анонимные админы и посты каналов приходят в Telegram как «боты»
   (`GroupAnonymousBot`, `Channel_Bot`) — Cleanny их специально не трогает.

## Подготовка

1. **@BotFather**: создайте бота, отключите Group Privacy (`/mybots` → бот →
   Bot Settings → Group Privacy → Turn off), чтобы бот видел все сообщения.
   Чтобы бот видел сообщения *других ботов*, нужен включённый режим
   Bot-to-Bot Communication в настройках бота (мини-приложение BotFather).
   После смены этих настроек бота нужно убрать из группы и добавить заново.
2. Добавьте Cleanny в группу и назначьте администратором с правом
   **«Удаление сообщений»**.
3. Напишите боту `/start` в личные сообщения — туда он будет присылать вам
   оповещения (`OWNER_USER_ID`).

## Переменные окружения

| Переменная | Что это | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен от BotFather (обязательно) | — |
| `DATABASE_URL` | строка подключения PostgreSQL | локальный SQLite |
| `OWNER_USER_ID` | ваш Telegram ID | 828533150 |
| `DELETE_DELAY_SECONDS` | задержка удаления по умолчанию | 300 |
| `WHITELIST_BOT_IDS` | боты, которых не трогать во всех чатах | пусто |
| `DEFAULT_UTC_OFFSET_HOURS` | часовой пояс по умолчанию | 5 |
| `TIDY_DELAY_SECONDS` | через сколько убирать ответы Cleanny | 90 |
| `NIGHT_FAST_DELAY_SECONDS` | задержка ночного режима fast | 30 |
| `WATCHDOG_INTERVAL_SECONDS` / `WATCHDOG_PENDING_THRESHOLD` | настройки сторожа | 300 / 30 |

На облачном хостинге **обязательно задайте `DATABASE_URL`** (PostgreSQL), иначе
настройки и очередь хранятся в файле SQLite и пропадают при передеплое.
Адреса `postgres://` и `postgresql://` принимаются оба.

## Команды

**Для всех:** `/start`, `/help`, `/status`

**Для админов группы:**

| Команда | Что делает |
|---|---|
| `/settings` | меню настроек на кнопках |
| `/setdelay 5` | задержка удаления (`30s`, `10m`, `2h`; число — минуты; до 48 ч) |
| `/botdelay @бот 10` | своя задержка для конкретного бота; `reset` — сбросить; `list` — показать |
| `/pause 1h` | пауза; `/pause 1h cancel` отменяет и уже запланированные удаления |
| `/resume` | снять паузу |
| `/keep` | ответом на сообщение бота: оставить его |
| `/whitelist add\|remove\|list` | боты, которых не трогаем |
| `/mode all\|only` | чистить всех или только ботов из `/targets` |
| `/targets add\|remove\|list` | список ботов для режима `only` |
| `/cleancmds on\|off` | удалять и команды людей вида `/cmd@бот` |
| `/cleanvia on\|off` | удалять сообщения, отправленные через inline-режим бота |
| `/tidy on\|off` | убирать ответы Cleanny и команды админов |
| `/night 23:00-08:00 [skip\|fast]` | ночной режим: не удалять / удалять быстро; `/night off` |
| `/timezone +5` | часовой пояс чата |
| `/stats` | сколько удалено сегодня / за 7 и 30 дней, топ ботов |

**Только владелец, в личке:** `/chats` — где бот состоит и в каком статусе;
`/stats` — статистика по всем чатам.

Бота можно указать по `@username` (если он уже писал в чатах, где есть
Cleanny) или ответом на его сообщение. Владелец бота может выполнять админские
команды в любом чате.

## Оповещения владельцу

- Cleanny потерял право удалять сообщения или его убрали из чата;
- удаление падает с ошибкой прав (не чаще раза в час на чат);
- необработанное исключение в обработчике;
- сторож: у Telegram накапливаются необработанные обновления (так выглядело
  падение из-за старой версии aiogram) или связь пропадала и вернулась.

Сторож опирается на поле `pending_update_count` из `getWebhookInfo`.

## Запуск

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впишите BOT_TOKEN
python bot.py
```

На хостинге: переменные окружения в панели, свой Dockerfile включён,
`DATABASE_URL` указывает на PostgreSQL. При обновлении жмите «Пересобрать».

## Ограничения

- Удалить можно только сообщения не старше 48 часов.
- Бот не видит, на какие слова реагируют другие боты («ферма» и т. п.), поэтому
  такие сообщения людей он не уберёт. `/cleancmds` работает для команд с `@`.
- `deleteMessages` не сообщает, какие именно сообщения не удалились, поэтому
  статистика считает сообщения, отправленные на удаление.
